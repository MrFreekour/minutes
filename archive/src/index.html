    Optional next step

    Open your documents so you can search them

    This opens your PDFs, Word, OpenDocument, RTF, text, and Markdown files, and reads scanned images with the text reader built into macOS. Text from a scan is a machine reading a picture, so it is never quoted as the document's own words. Everything is read on this Mac, by helper programs that have no network access, and it is all held in memory — nothing is written to disk. Scans, very old Word files, and email archives are counted but not searched.
